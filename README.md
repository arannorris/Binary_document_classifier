# Binary_document_classifier
A binary document classifier made during my Natural Language Processing Module during my MSc in Data Science.
It includes splitting of data into training and testing samples, word pre-processing, multiple simple classifications, including a self-made Naive Bayes' classification function, and a confusion matrix to calculate recall, precision, and f1.
I tested it first on simple self-made documents on weather and football, then trained and tested it on movie_reviews from nltk. I found the f1 score to be better than the nltk NaiveBayesClassifier.
